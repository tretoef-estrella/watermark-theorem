**F1 — line 58 (§1.3). ERROR.** «the eigenline of `a` has Hodge type `(k, k)` exactly when `a ∈ 𝔅`» is false. By [SK] the eigenline of `a` has type `(k, k)` exactly when `Σ_ν {a_ν/m} = k + 1`; `𝔅` asks this for every unit multiple `ta`. Example: `m = 5`, surface, `a = (1, 3, 3, 3)`: type `(1, 1)`, but `2a = (2, 1, 1, 1)` has type `(2, 0)`, so `a ∈ T`. The conclusion (1) is right; the argument should read: *a class `xe ∈ H°` is rational, so the set of `a` with `χ_a(x) ≠ 0` is Galois-stable; it is a Hodge class iff that set lies in the characters of type `(k,k)`, iff it lies in `𝔅`. Hence `Hdg° = I_T e`. And `ye ⊥ I_T e` iff `xȳθ = 0` for all `x ∈ I_T`, iff `χ_a(y) = 0` on `−𝔅 = 𝔅`; hence `T(X) = I_𝔅 e`.* (The second half is not written in the note at all; it needs that for each `a ∈ 𝔅` some element of `I_T` does not vanish at `a`, e.g. `|G|` times the sum of the idempotents of the Galois orbit of `a`.)
